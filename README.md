# Monarch Labs — website

Static site, no build step. Open `index.html` in a browser or serve the folder.

```
index.html          Hero: service reel (Strategy, Experience, Intelligence, Knowledge, Automation, Creative)
capabilities.html   Capabilities
studio.html         Studio
contact.html        Contact
styles.css          Site styles      studio.css  Inner-page styles
preload.js          Preloader        hero.js     Reel, menu, scroll steps
work.js             Concept-study work view   studio.js / contact.js  Inner pages
work/               Study screens (WebP)
favicon.svg
```

All concept studies use fictional brands.
